01
Brand Foundation

ブランドの輪郭

ロゴのキューブモチーフは、専門家・運営者・法人がつながり「共に問題を解決する」協会の役割を象徴します。シンボルの濃淡ブルーは、公益性の誠実さと、開かれた透明性を同時に表現しています。

Brand Voice

誠実 × 専門 × 親身

かしこまりすぎず、軽すぎない。専門家の信頼感と、運営担当者に寄り添う温度感を両立した文体・ビジュアルを目指します。一次情報の正確性を最優先しつつ、難解にせず「分かる言葉」で語ります。

Voice & Tone — 文体の3原則

誠実 — 正確に、断定する

関連法令・通達に基づく正確な記述を最優先。曖昧な表現や過度な誇張は避け、根拠を明示します。

明快 — 短く、構造的に

1文40字以内を目安。専門用語は初出時に補足。要点→詳細の順で、運営担当者の判断速度を上げる文章に。

親身 — 「お悩みの方へ」

運営の現場感に寄り添う言葉選び。「させていただく」より「いたします」を基本に、距離感のある丁寧語で。

3書体の役割とウェイト

書体は3つ、役割は固定

Noto Sans JP が既定（本文・見出し・UI・和暦）。Noto Serif JP はヒーローの h1 だけ（§15-1。太明朝 700 以上は禁止）。Inter は欧文と算用数字だけ。明朝をセクション見出しや本文に広げない、Inter を和文に当てない。

使うウェイトは 400 / 500 / 700 の3段

見出しは 700 で止める。900（Black）は財団サイトでは使わない（v1.0 §03 の Display 900 は協会サイト側の規定）。600 は Serif のキャッチと Inter のエイブロー専用で、和文 Sans には当てない。

和文・欧文の組み合わせルール

① 英語見出しは Inter

「SHIBUYA AWARD」のような英字キーワードは Inter 700、字間 +.26em〜+.35em でゆったり組む。和文より一段小さく置く。ブランド名「シェアコモン200」はカタカナ表記で統一し、英語表記は使用しない。

② 数字は Inter / Tabular

金額・年度・パーセントは Inter で統一。font-feature-settings: "tnum" で表組での揃えを担保。

③ 和暦に Inter は当てない

「令和7年11月17日」のような和暦・和文混在は Noto Sans JP のまま、tabular-nums だけを効かせる。Inter を当てるのは西暦の日付・金額・件数。

④ 約物半角は palt

body 全体で font-feature-settings: "palt" 1、CMS の長文本文（.prose）では normal に戻す。見出し・UI は詰め、長文は標準送り。

Font Stack — Web は stack を手書きしない

Web（next/font）

フレームワークが生成する CSS 変数をそのまま使う。フォールバックは metric-adjusted な local(Arial) 1枚で、Hiragino / Yu Gothic は Web の stack に入らない。CJK は unicode-range 分割で配信されるため、subsets: ['latin'] でも和文グリフは読み込まれる。

印刷・スライド・その他の媒体

--ff-jp / --ff-jp-serif / --ff-en の stack を使う（巻末トークン参照）。等幅（JetBrains Mono）は現状どの実装でも未使用。

09
Logo Usage

ロゴ使用ルール

ロゴは協会の最重要資産です。最小サイズ・余白・配色を守り、改変は行わないでください。下記ルールに沿って使用することで、媒体をまたいだ一貫性を保ちます。

Clear Space — 周囲の余白

x x x x

最小余白 = キューブシンボルの高さ x

ロゴ周囲には、シンボル（キューブ部分）の高さと等しい余白 x を必ず確保。他要素・写真・テキストはこの領域に侵入させないでください。

最小サイズ

  • Web: 高さ 32px 以上（キューブ部分の視認性を担保）
  • 印刷: 高さ 10mm 以上
  • 名刺・ファビコン用に、シンボルのみの単色版も使用可

Background Rule — 必ず白背景の上に配置

!
ロゴは必ず白（#FFFFFF）の地の上に配置します。白抜き（ノックアウト／反転）・くり抜きは不可です。色面・写真・グラデーションの上に直接置きたい場合は、ロゴを白い長方形プレート（角丸 4px、十分なクリアスペース）に載せ、そのプレートを背景に重ねてください。
A. 標準（白背景にそのまま配置） B. ダーク面 → 白プレートに載せる C. 写真・色面 → 白プレートに載せる

Do & Don't — 使用ガイド

✓白背景にそのまま配置（標準）
✓ダーク面では白プレートに載せる
✓十分なクリアスペースを確保
✕白抜き（ノックアウト／反転）にしない
✕ブレンドモード等で背景に溶け込ませない
✕縦横比を変えて変形しない
✕ブランド外の色相に変更しない
✕色面・写真の上に直接重ねない
✕ロゴをくり抜き処理にしない

アクセシビリティ補正

v1.0 の配色を WCAG 2.1 AA（通常文字 4.5:1 / 大文字 3:1）で実測し、満たさない組み合わせを差し替えました。ここに載っている値が現行で、v1.0 の値は使いません。Navy 系は全項目良好だったため、補正はアクセント側だけです。

Blue 500 は「罫・アイコン・24px 以上の大きい図形」の装飾専用に格下げ。Blue 400 はホバー下線とダーク面のテキスト専用、Ink 500 は無効状態と装飾罫専用です。

インタラクションの規定

フォーカスは必ず見える

ボタン・リンク・タブに outline: 2px solid Blue 600 ／ outline-offset: 2px。入力欄は Blue 600 の枠線＋4px のリング。

お問合せ

タップは 44×44px 以上

モバイルのボタン・ナビ項目・リスト行リンクは 44px 以上の高さを確保する。文字サイズを上げるのではなく、余白で確保する。

状態は色だけで示さない

「完了・受付中」は Navy 700 を流用するためブランド色と区別できない。チェック印＋テキストラベルを併記する（WCAG 1.4.1）。

モーション

演出は入場の1パターンだけ

0.6s / cubic-bezier(.22,1,.36,1) / 14px 上昇＋フェード。ヒーロー内は 60〜280ms のディレイで順に立ち上げる。カードは hover の 2px 上昇と影のみ。

prefers-reduced-motion で止める

装飾的なアニメーションは reduce で無効化するか、単純な色変化に置き換える。動きを前提にした情報提示をしない。

Web Implementation

Web 実装の規定

財団サイト（koueki.or.jp）の実装で確定した規定です。写真ヒーロー・白ハロ・画像比率・トークン名前空間は、グループの他サイトにも同じ形で適用します。

写真の上のテキストは「白ハロ」で浮かせる

写真を全幅背景にして濃紺の文字を直接載せる場合、白いぼかしの縁取り（text-shadow 4段）で可読性を確保します。白抜き文字にはしません。ロゴだけは別ルールで、白いプレートに載せます（§09）。

ヒーローの構成順

グループ帰属バッジ（Navy 800 のピル / 12px）→ 英字エイブロー → Serif キャッチ（2行・句読点なし・改行で区切る）→ リード 16px → 補足 14px → CTA 2つ（Primary ＋ Outline）。文字側には白のフェード（rgba(255,255,255,.65) → transparent）を重ね、写真上のアウトラインボタンには rgba(255,255,255,.7) ＋ backdrop-filter: blur(4px) を敷きます。オレンジのキャッチピルは使いません。

画像枠は実比率に合わせる（白帯禁止）

枠を画像の比率に合わせる

記事タイトル画像は OGP 規格の 1200×630 なので、枠も aspect-ratio: 1200 / 630 にして object-fit: cover で敷き詰める。

contain は使わない

比率が合わないと上下（左右）に白帯が出て、角丸との間に隙間が見える。比率が混在する画像は cover の軽微なトリミングで吸収する。

読み込み中の下地

白ではなく Blue 100（#E6F3FB）などの淡色を敷く。白だと画像との継ぎ目が目立つ。

レイアウトの確定値

項目値
コンテナ最大 1240px / 左右余白 20px（〜767px）→ 32px（768px 以上）
読み物カラム一覧・表・タイムライン 880px ／ 記事本文 768px
セクション余白上下 64px → 96px（768px 以上）
角丸カード 16px ／ アイコン枠・人物写真 10px ／ ボタン・バッジはピル
影常用は --sh-3 のみ。階層は hover の 2px 上昇で出す

トークン名の衝突を避ける

独立した名前空間を使う

本書の --blue-* はユーティリティ CSS 標準のパレットと衝突するため、Web 実装では accent-600〜accent-100 のように別名で宣言する。Navy / Ink / 影（shadow-e1〜e4）も同様。

--color-blue-* を上書きしない

CMS に保存済みのリッチテキストが text-blue-800 のような標準クラスを直接含むことがある。上書きすると既存記事の見た目が黙って変わる。

お問合せの導線 — 電話番号の置き場所

ページ内のお問合せブロック

住所 ＋ フォーム（Primary） ＋ メール（Outline）。電話番号は載せない。左は Navy 900 → Navy 700 のグラデに白文字、エイブローは Blue 300 に置き換える。
